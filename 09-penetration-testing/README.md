# 09 — Penetration Testing

## Assessment Methodology

My working methodology is built around a repeatable lifecycle:

```
1. Scope
2. Reconnaissance
3. Enumeration
4. Vulnerability Analysis
5. Validation / Exploitation
6. Post-Exploitation
7. Privilege Escalation
8. Impact Analysis
9. Remediation
10. Reporting
```

## Reporting Standard

For each significant finding I aim to document:

- Title
- Affected asset
- Severity rationale
- Technical description
- Preconditions
- Reproduction steps
- Evidence
- Business/security impact
- Remediation
- References

## Principle

A professional penetration test is more than obtaining access. The objective is to produce reliable evidence and actionable remediation within the authorized scope.
