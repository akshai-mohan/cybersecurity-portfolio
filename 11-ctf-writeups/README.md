## Write-up Standard

Each write-up is structured around:

1. Scope and target
2. Reconnaissance
3. Enumeration
4. Initial access
5. Privilege escalation
6. Evidence / key findings
7. Lessons learned
8. Defensive perspective

Commands are included for educational reproducibility, with sensitive or unnecessary exploit details omitted where appropriate.
