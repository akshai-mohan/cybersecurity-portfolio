# Security Policy

## Scope

This repository contains cybersecurity learning notes, authorized-lab documentation, CTF write-ups, defensive observations, and security research performed in controlled environments.

## Responsible Use

The techniques documented here are intended for:

- Systems I own or have explicit permission to test
- Local virtual machines and home labs
- Intentionally vulnerable training platforms
- CTFs and authorized security assessments

Do not use the material to access, disrupt, or test systems without authorization.

## Reporting

If you identify a security issue in this repository itself, please open a GitHub issue with enough detail to reproduce the problem without exposing sensitive information.

## Secrets

Credentials, API keys, private IPs that should not be public, tokens, and other sensitive information must never be committed to this repository.
